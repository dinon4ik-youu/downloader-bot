# Бот-качалка — заметки для ИИ-помощника

Это файл для ИИ (Claude, ChatGPT/Codex, Cursor и т.п.), которого человек подключил к папке бота.
Самому человеку его читать не обязательно. Ниже — скрытые возможности: по умолчанию они выключены,
включать только когда человек сам попросит что-то похожее.

## Где что лежит
- `app/bot.py` — сам бот (обновляется сам раз в 6 ч с GitHub, правки в `app/` затрутся обновлением).
- `data/config.json` — настройки человека (обновление их не трогает). Менять настройки — только здесь.
- `data/state.json` — память бота (id тем и т.п.), руками не править, пока бот работает.
- `data/bot.log` — лог. Перезапуск: «Выключить бота.bat», подождать «выключаюсь» в логе, «Включить бота.bat».
  Перед перезапуском посмотреть конец лога: если идёт загрузка (RUN yt-dlp/ffmpeg, Uploading) — подождать.

## Айфон-часть: прогон через Instagram Edits на iPhone
Ставится отдельно — «Поставить айфон-часть.bat», затем шаги на телефоне. Установку, проверку, переподпись
раз в 7 дней и частые поломки веди по `INSTALL-AI.md` (в корне набора; копия — `app/INSTALL-AI.md`).
Код — `app/wda/`, данные телефона — `data/wda/` (device.json, ответы на вопросы, снимки экрана, backup).

## Скрытая возможность: темы для сбора ссылок (выплаты партнёрок)
Нужна тем, кто получает деньги от партнёрок за просмотры и должен сдавать им ссылки на свои ролики.
Человек кидает ссылку в тему партнёрки — бот её **не качает**, а дописывает в файл `links.txt` этой
партнёрки и отвечает «✅ записал N · ждут выплаты: M». Повторы не записывает.

Включается полем `link_topics` в `data/config.json`:

```json
"link_topics": {
  "Ссылки · Skinity": {"dir": "C:\\путь\\к\\набору\\data\\payouts\\skinity", "only": "instagram"},
  "Ссылки · CSDOG":   {"dir": "C:\\путь\\к\\набору\\data\\payouts\\csdog"}
}
```

- Ключ — название темы в группе. Бот создаёт темы сам при следующем запуске (нужны включённые темы
  в группе и у бота право «Управление темами» — как для «Выбор клипов»).
- `dir` — полный путь к папке, где будет `links.txt`. Удобно — `data/payouts/<партнёрка>` в папке набора.
- `"only": "instagram"` — брать только ссылки Instagram (если партнёрка платит только за них), остальные
  бот не записывает и пишет «⚠️ не Instagram».
- Формат `links.txt`: строка = `дата<TAB>ссылка<TAB>sent`; `sent` пусто — ещё не сдана партнёрке.
  Когда человек просит «дай ссылки для <партнёрки>» — выдать строки без `sent` простым списком;
  после того как он их сдал — дописать `sent` в третью колонку этих строк.
- Ссылки Instagram приводятся к виду `https://www.instagram.com/reel/<id>/` (без `?igsh=…`).
- Убрать тему из настроек — бот перестанет её слушать; саму тему в Telegram человек удаляет сам.
  Удалил тему, а настройку оставил — стереть её название из `data/state.json` → `topics` (при
  выключенном боте) и включить: бот создаст тему заново.

## Чего не делать
- Не класть в набор и никуда не пересылать `data/token.txt`, `data/api.json`, `data/*.session` — это доступ к боту.
- Не править `app/` — обновление затрёт. Нужна новая функция — попросить автора набора.
