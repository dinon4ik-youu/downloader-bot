# Установка айфон-части — инструкция для ИИ-помощника

Этот файл — для ИИ (Claude Code, Gemini CLI, ChatGPT / Codex и т.п.), которому человек открыл папку набора и
сказал «поставь айфон-часть» / «настрой Edits». Веди человека **по одному шагу**: скажи, что сделать, дождись
«готово», проверь сам, где можешь, и только потом следующий шаг. Отвечай на его языке, без воды.

## Что получится
Готовые вертикальные видео (9:16) из бота прогоняются через настоящее приложение **Instagram Edits** на iPhone,
подключённом к компьютеру кабелем: на выходе настоящий айфонный экспорт (HEVC 1440×2560, 60 fps). Телефоном управляет
**WebDriverAgent (WDA)** — тестовая программа Apple-разработчиков; компьютер жмёт кнопки на экране сам.
Видео попадают в «Фото» по кабелю: папка приложения **VLC** + быстрая команда **EditsIn**. Telegram на айфоне не нужен.

Пути ниже — от корня набора (где `install.bat`). `PY` — Python набора:
`%LOCALAPPDATA%\Programs\Python\Python312\python.exe`.

## Что нужно заранее
- Windows 10/11, бот набора уже поставлен (`install.bat`) и работает.
- iPhone с iOS 17 или новее и **кабель с передачей данных** (не только зарядный).
- **Отдельный Apple ID для подписи WDA** — не основной, лучше завести новый (бесплатный). Пароль и код из SMS/почты
  человек вводит сам, в Sideloadly; ИИ их не спрашивает и никуда не записывает.
- Аккаунт Instagram, в который человек войдёт в Edits.

## Часть 1 — компьютер
1. Запустить **«Поставить айфон-часть.bat»** (если на вопрос в `install.bat` уже ответили «да» — это сделано).
   Ставит pymobiledevice3, ffprobe, драйвер Apple, задачу «WDA tunnel», Sideloadly и включает в боте темы.
2. Шаг «Драйвер iPhone»: если `winget` нет — откроется Microsoft Store с **Apple Devices** → «Получить» →
   после установки запустить bat ещё раз. Проверка: `Get-AppxPackage AppleInc.AppleDevices` что-то выводит.
   Магазина нет («Не удаётся открыть ссылку windows-store» — урезанная Windows): поставить iTunes с сайта
   Apple (apple.com/itunes, версия для Windows, не из Microsoft Store) — с ним ставится тот же драйвер iPhone.
   Проверка тогда: `Get-Service 'Apple Mobile Device Service'` в состоянии Running.
3. Шаг «Туннель»: появится окно Windows «Разрешить вносить изменения?» → «Да». Проверка: есть файл
   `data\wda\tunnel-task.ok`. Нет — смотреть `data\wda\tunnel-task.log`.
4. Шаг «Sideloadly»: установщик — «Далее» до конца.
5. Перезапустить бота («Выключить бота.bat», подождать, «Включить бота.bat») — в группе появятся темы
   **«Кинуть в Edits»** и **«Вопросы прогона»**. Вопросы с телефона приходят во вторую.

## Часть 2 — айфон
6. Подключить iPhone кабелем, разблокировать → **«Доверять этому компьютеру»** → ввести код телефона.
   Проверка: `PY -m pymobiledevice3 usbmux list` показывает телефон.
7. Из App Store поставить **Edits** (Instagram), **VLC media player** (VideoLAN) и **Команды** (Shortcuts, обычно уже есть).
   Открыть Edits, войти в Instagram, пройти приветствие до экрана с кнопкой «+». Открыть VLC один раз.
8. **Подписать WDA.** Запустить «Переподписать WDA.bat» (откроет Sideloadly и покажет файл):
   - в Sideloadly выбрать телефон, в поле Apple ID — отдельный Apple ID из «Что нужно заранее»;
   - перетащить `app\wda\WebDriverAgent.ipa` в окно → **Start** → ввести пароль и код подтверждения.
   - Ошибка «macho sign/edit failed» — IPA повреждена, скачать набор заново.
9. На айфоне: **Настройки → Основные → VPN и управление устройством** → профиль с этим Apple ID → «Доверять».
10. **Режим разработчика:** Настройки → Конфиденциальность и безопасность → Режим разработчика → включить →
    перезагрузка → после неё «Включить». (Пункт появляется только после шага 8.)
11. **Папка для видео:** приложение «Файлы» → «На iPhone» → **VLC** → долгое нажатие на пустом месте →
    «Новая папка» → `edits-in`.
12. **Быстрая команда EditsIn:** открыть на айфоне ссылку
    https://www.icloud.com/shortcuts/c9be0fa29b85412b85b37853a84191ee → «Добавить быструю команду» → на вопросе
    про папку выбрать **VLC → edits-in**. Имя оставить **EditsIn** (скрипт запускает её по имени).
13. **Автоблокировка — «Никогда»** на время прогонов (Настройки → Экран и яркость). Иначе экран погаснет посреди прогона.

## Часть 3 — проверка
14. Связь: `PY app\wda\start.py` (телефон разблокирован). В конце должно быть «WebDriverAgent готов»; адрес
    http://127.0.0.1:8100/status отвечает. Первый запуск сам найдёт телефон и WDA и запомнит их
    в `data\wda\device.json` (сменили телефон или переподписали другим Apple ID — удалить этот файл).
15. Пробный прогон одного видео: положить любой вертикальный mp4 9:16 в папку, например `D:\edits-test`, и
    `PY app\wda\edits_iphone.py D:\edits-test --only 1`. Первый раз телефон спросит разрешения
    («EditsIn хочет сохранить в Фото», доступ Edits к «Фото») — нажать «Разрешить» / «Разрешить доступ ко всем».
    Готово, когда видео в папке заменилось экспортом 1440×2560 и рядом появился `.iphone-done.txt`.
16. Дальше человек пользуется из бота: кнопка «📱 Прогнать через Edits» под видео в «Отобранных» или тема
    «Кинуть в Edits».

## Раз в 7 дней — переподписать
Бесплатная подпись Apple живёт 7 дней. Скрипт пишет «подпись WDA до …», за 2 дня предупреждает в «Вопросах прогона».
Переподписать: «Переподписать WDA.bat» → тот же Apple ID → Start. Ничего на айфоне заново делать не надо.

## Если сломалось
| Симптом | Что сделать |
|---|---|
| `usbmux list` пустой | другой кабель / порт, разблокировать, заново «Доверять»; Apple Devices установлен? |
| «на iPhone нет WebDriverAgent» | шаг 8 не прошёл — подписать снова |
| «WebDriverAgent не ответил» | телефон заблокирован, нет «Доверять» разработчику (шаг 9), выключен режим разработчика (10), истекла подпись |
| окно UAC при каждом запуске | задача «WDA tunnel» не создана — шаг 3, смотреть `tunnel-task.log` |
| «нет …shortcut.json» | не было первого запуска с набором: запустить `start.py` ещё раз (файл кладётся из `app\wda\defaults`) |
| видео не появляется в «Фото» | нет папки `edits-in` в VLC (шаг 11) или в команде выбрана другая папка — удалить команду и добавить заново |
| скрипт спрашивает кнопку в «Вопросах прогона» | ответить номером из списка или скрином с точкой — запомнит и дальше сам |
| интернет компьютера пропал при подключении | Windows пустила его через айфон: на айфоне выключить «Режим модема» |

Разведка экрана, если надо разобраться: `PY app\wda\wda.py shot имя` (снимок в `data\wda\shots`),
`PY app\wda\wda.py tree имя` (кнопки с надписями), `PY app\wda\explore.py имя`.

## Правила
- Пароль Apple ID, коды подтверждения, `data\token.txt`, `data\api.json`, `data\*.session` — никуда не пересылать.
- Не править `app\` — автообновление затрёт. Настройки человека — только в `data\`.
- Не удалять исходники из папки, которую прогоняют: оригиналы перед заменой кладутся в `data\wda\backup\`.
